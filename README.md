# Desarrollo de Interfaces

Prácticas y apuntes del módulo Desarrollo de Interfaces (DI), 2º DAM, curso 2026-27, IES Isidra de Guzmán.

El material de estudio es el curso abierto **Interfaces de Usuario (2021)** de la Universidad Carlos III de Madrid (OCW), completo: <https://ocw.uc3m.es/course/view.php?id=268>. El índice del curso está en [`guia-de-aprendizaje.png`](guia-de-aprendizaje.png).

## Contenido

| Carpeta | Qué hay |
|---|---|
| [`tema-1-interaccion-persona-ordenador/`](tema-1-interaccion-persona-ordenador/) | Apunte 1.1 y ejercicios del Modelo de Norman (enunciados, soluciones y resueltos) |
| [`tema-2-interfaces-de-usuario/`](tema-2-interfaces-de-usuario/) | Apuntes 2.1 a 2.4 (interfaces, usabilidad, metodología y prototipado, accesibilidad) y ejercicios de HTA, GOMS y KLM |
| [`tema-3-interfaces-de-usuario-web/`](tema-3-interfaces-de-usuario-web/) | Apuntes 3.1 y 3.2 (diseño web y sus principios) y ejercicios de prototipado y heurísticas de Nielsen |
| [`tema-4-la-interaccion-con-las-interfaces/`](tema-4-la-interaccion-con-las-interfaces/) | Apuntes 4.1 (diseño de la interacción) y 4.2 (métodos de evaluación e inspección) |
| [`tema-5-interfaces-de-usuario-avanzadas/`](tema-5-interfaces-de-usuario-avanzadas/) | Apunte 5.1 (paradigmas de interacción) |
| [`practicas/`](practicas/) | `tecnologias-web.pdf` (HTML5, CSS3, JavaScript y jQuery, base de todas las prácticas) y una carpeta por práctica: 1 HTML5 y CSS3, 2 JavaScript y jQuery, 3 metodología de diseño y prototipado |
| [`caso-practico/`](caso-practico/) | Enunciado del caso práctico (tema 4) |
| [`examenes/`](examenes/) | Exámenes de toda la asignatura de las convocatorias ordinarias de enero de 2016, 2017 y 2018, con sus soluciones |
