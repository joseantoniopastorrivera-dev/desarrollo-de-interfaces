# Desarrollo de Interfaces

Prácticas y apuntes del módulo Desarrollo de Interfaces (DI), 2º DAM, curso 2026-27, IES Isidra de Guzmán.

El material de estudio viene del curso abierto **Interfaces de Usuario** de la Universidad Carlos III de Madrid (OCW): <https://ocw.uc3m.es/course/view.php?id=268>. El índice completo del curso está en [`guia-de-aprendizaje.png`](guia-de-aprendizaje.png).
