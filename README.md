# Desarrollo de Interfaces

Prácticas y apuntes del módulo Desarrollo de Interfaces (DI), 2º DAM, curso 2026-27, IES Isidra de Guzmán.

Hay dos fuentes de material:

- **Aula virtual del módulo (DAM2-DI, EducaMadrid)**: lo que se da en clase y se evalúa. Las prácticas son en **Java con Swing y NetBeans**.
- **Curso abierto *Interfaces de Usuario (2021)* de la UC3M** (OCW), completo: <https://ocw.uc3m.es/course/view.php?id=268>. Es la teoría que enlaza la Unidad 1 y 4 del aula virtual. Sus prácticas usan HTML5, CSS3, JavaScript y jQuery. El índice del curso está en [`guia-de-aprendizaje.png`](guia-de-aprendizaje.png).
